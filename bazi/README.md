# Bazi Lab — آزمایشگاه رادیو، تلویزیون، ویدئو و هایفای

اپ وب آفلاین (PWA) با رابط فارسی که چهار دستگاه قدیمی را **درون خودش** شبیه‌سازی می‌کند و یک **آزمایشگاه جدا** برای ساخت برنامه و آزمودن مفهوم و مدل کار این فناوری‌ها دارد.
همه‌چیز ساختگی است: هیچ شبکه، میکروفن یا سخت‌افزار رادیویی واقعی استفاده نمی‌شود. بدون وابستگی و بدون build.

## دستگاه‌ها
| دستگاه | چه چیزی شبیه‌سازی شده |
|---|---|
| 📻 رادیو | AM / FM استریو / موج کوتاه؛ انتخاب‌پذیری و پهنای باند، نویز، محوشدن، سوت تداخل، اثر غلبهٔ FM، اسکوئلچ، جستجو، پیش‌تنظیم‌ها، اثر روز/شب |
| 📺 تلویزیون | CRT با PAL/NTSC، تیونر کانال، برف، ارواح (چندمسیری)، هماهنگی افقی/عمودی (رول)، رنگ/فام/تضاد، ورودی AV |
| 📼 ویدئو | نوار (SP/LP)، ضبط/پخش/جلو/عقب/مکث، ضبط زمان‌بندی‌شده، ردیابی، فرسودگی، نوار قفل‌شده، نقشهٔ نوار |
| 🎛 هایفای | تیونر، CD، گرامافون (RIAA، سرعت ۳۳/۴۵)، ورودی TV و VCR، بم/زیر/لودنس، EQ ۷ باند، اتاق، VU، طیف‌نما، لیساژو، LED برش |

## آزمایشگاه
- **محیط اتر**: نقشهٔ فرستنده‌ها و گیرنده قابل جابجایی، نویز جوی، تداخل، چندمسیری، روز/شب، شتاب زمان. روی همهٔ دستگاه‌ها اثر می‌گذارد.
- **مدولاسیون**: AM و FM با دمدولاتور I/Q، طیف FFT، قاعدهٔ کارسون، اثر نویز.
- **سوپرهترودین**: LO، IF، فرکانس تصویر، فیلتر RF و ایستگاه شبح.
- **اسکن تلویزیون**: خط‌به‌خط، دو میدان (interlace) و موج مرکب (سنک، بورست، روشنایی).
- **هد دوار ویدئو**: اسکن مارپیچ، پهنای شیار SP/LP/EP، انحراف ردیابی.
- **آمپلی‌فایر**: برش نرم/سخت/لامپی، THD، هارمونیک‌ها، منحنی RIAA.
- **استودیوی برنامه**: ساخت ایستگاه رادیو یا شبکهٔ تلویزیون (موسیقی/گفتار + تصویر)، موقعیت و توان، پخش در اتر؛ فوراً با همهٔ دستگاه‌ها قابل دریافت و ضبط است.
- **آزمون خودکار** (۱۶ آزمون) و **دفتر آزمایش** (ثبت و دانلود JSON).

## اجرا
فایل‌ها را در ریشهٔ ریپو بگذارید. روی GitHub: Settings ← Pages ← Source: **GitHub Actions** (گردش‌کار آماده است)، یا Branch: main / root.
محلی: `python3 -m http.server` و باز کردن `http://localhost:8000`. (برای نصب PWA و کار آفلاین، آدرس باید https یا localhost باشد.)

APK: Actions ← **Build Android APK** ← Run workflow (Capacitor؛ آزمایش‌نشده روی این محیط).

## ساختار
`js/util.js` ابزار • `ui.js` اجزای رابط • `world.js` اتر و مدل انتشار • `audio.js` موسیقی و موتور صدا • `video.js` صحنه‌ها • `radio.js` `tv.js` `vcr.js` `hifi.js` دستگاه‌ها • `lab.js` `studio.js` آزمایشگاه • `app.js` راه‌اندازی.
